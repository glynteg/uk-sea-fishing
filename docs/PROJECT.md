# Project direction

## Purpose
Build a practical UK sea-fishing app with trustworthy local fishing information.

## Information trust model

### Verified
Information independently checked and approved for the app's verified database.

### Community submitted
Information supplied by anglers but not yet independently verified. It must remain visibly labelled as unverified.

### Important rule
Never manufacture a fishing mark, coordinate, species record, access detail, or local fishing claim to fill a gap in the database.

## First release priorities
1. App shell and navigation
2. Fishing marks data model
3. Map and mark browsing
4. Mark detail pages
5. Submission workflow
6. Tides/weather integration
7. Accounts
8. Premium subscription
