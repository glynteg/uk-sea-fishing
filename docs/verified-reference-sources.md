# Verified reference sources

## Angling Direct — UK sea angling marks guide

- **Status:** Accepted as a verified reference source for named sea-fishing venues.
- **Publisher:** Angling Direct
- **Article title:** Top Sea Angling Marks - Where Can You Go Sea Fishing in the UK?
- **Published:** 2 April 2021
- **URL:** https://www.anglingdirect.co.uk/community/top-sea-angling-marks-where-can-you-go-sea-fishing-in-the-uk/
- **Coverage:** The guide is organised by UK regions and names sea-fishing locations, with information such as species, access, directions and parking.

### How to use this source

A named venue explicitly described as a sea-fishing mark in this guide can be treated as **verified as a fishing venue**, with this article recorded as its source.

This does **not** automatically verify that every detail remains current. Check coordinates, current access and restrictions, parking, hazards, child suitability, disabled access, species reports and seasonal advice separately where possible. The article dates from 2021, so time-sensitive details should not be copied as current without a fresh check.

Do not infer exact coordinates from a place name. If a reliable location cannot be established, leave the mark unmapped or label its location accuracy appropriately.
