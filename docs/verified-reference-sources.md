# Verified reference sources

## Angling Direct — UK sea angling marks guide

- **Status:** Accepted as a verified reference source for named sea-fishing venues.
- **Publisher:** Angling Direct
- **Article title:** Top Sea Angling Marks - Where Can You Go Sea Fishing in the UK?
- **Published:** 2 April 2021
- **URL:** https://www.anglingdirect.co.uk/community/top-sea-angling-marks-where-can-you-go-sea-fishing-in-the-uk/
- **Coverage:** The guide is organised by UK regions and names sea-fishing locations, with information such as species, access, directions and parking.

### How to use this source

A named venue explicitly described as a sea-fishing mark in this guide can be treated as **verified as a fishing venue**, with this article recorded as its source.

This does **not** automatically verify that every detail remains current. Check coordinates, current access and restrictions, parking, hazards, child suitability, disabled access, species reports and seasonal advice separately where possible. The article dates from 2021, so time-sensitive details should not be copied as current without a fresh check.

Do not infer exact coordinates from a place name. If a reliable location cannot be established, leave the mark unmapped or label its location accuracy appropriately.

## Where's The Fish? — UK sea fishing map

- **Status:** Accepted as a source for verifying named sea-fishing venues when an individual page explicitly identifies the place as a sea-fishing mark.
- **Website:** Where's The Fish?
- **URL:** https://wheresthefish.uk/map
- **Coverage shown by the site:** UK coastal marks, region/county browsing, GPS locations, species lists, access notes, local mark guides, tides and weather/sea-condition forecasts.

### How to use this source

A named place explicitly identified on an individual page as a sea-fishing mark can be marked **verified as a fishing venue** in the app, with this website recorded as the source. A second source is not required just to verify that the venue is a fishing mark. This verification applies to the venue only, not automatically to every detail shown.

Do **not** treat forecast scores as a guarantee of catches or safety. Independently check exact coordinates, current access or closures, parking, hazards, child suitability, disabled access, and any legal size/bag limits or seasonal restrictions. The map's existence does not by itself verify every detail for every mark.

Do not copy seasonal advice or species lists blindly as proven facts for a particular mark. If location precision is uncertain, use the app's approximate/area-only labels or leave the mark unmapped rather than guessing.
