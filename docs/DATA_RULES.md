# Fishing data rules

Every fishing mark should have a provenance/status field.

Recommended statuses:
- verified
- community_unverified
- rejected

Coordinates must never be guessed. If coordinates have not been verified, they must not be presented as an official mark location.

Community content can include:
- mark descriptions
- species reports
- fishing tips
- photographs
- local observations

Community content must be labelled accordingly until verified.
