# UK Sea Fishing

A UK sea-fishing app focused on reliable, useful information for anglers.

## Core principles

- Verified fishing marks are clearly identified as verified.
- Angler-submitted marks and information are clearly labelled community-submitted/unverified until checked.
- No invented coordinates, marks, species claims, access information, or fishing advice are presented as verified facts.
- Free users get limited tides/weather information; Premium is planned at £4.99/month or £39.99/year.

## Planned features

- UK fishing marks map
- Verified and community-submitted marks
- Mark descriptions, species, tips and photographs
- Tides and weather
- Search and filtering
- Angler accounts and submissions
- Premium subscription

This repository is the development home for the UK Sea Fishing app.
